# LISN Search

Create a precise, reviewable LinkedIn Sales Navigator search URL. Keep this task separate from scraping, exports, enrichment, and campaign execution.

## Route the request

- Use a people search for leads, titles, seniority, employers, profile language, relationships, or recent activity.
- Use an account search for company size, headquarters, industry, followers, activity, hiring, or revenue.
- If a request mixes people and company-only facets, build separate URLs.

## Authorization boundary

Building or validating a URL does not authorize scraping, enrichment, outreach, or access to cookies and credentials.
